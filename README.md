# Innkeeper

Downloads for the Innkeeper PC app and addon, by [Lunyx](https://lunyx.dev).

Get it from the [Innkeeper page](https://lunyx.dev/innkeeper) or from the [latest release](https://github.com/LunyxDev/innkeeper-releases/releases/latest).

Compatible with World of Warcraft: Forever. Innkeeper is not affiliated with or endorsed by Blizzard Entertainment.
